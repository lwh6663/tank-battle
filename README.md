# 🎮 坦克大战 (Tank Battle)

一个使用原生 **HTML + CSS + JavaScript** 编写的经典坦克大战网页游戏，纯前端实现，无需任何依赖，打开即可游玩。

## ✨ 特性

- 🕹️ 经典 Battle City 玩法：移动、射击、破坏砖墙、保护基地（老鹰）
- 🤖 4 种敌军坦克：普通、快速、重甲、火花（掉落道具）
- ⭐ 3 种道具：护盾、加命、火力升级（3 级火力可击穿钢墙）
- 💥 砖墙可破坏、钢墙可防御、河流阻挡、树林隐蔽
- 📈 分数 / 最高分（本地保存）/ 关卡 / 剩余敌军 / 生命显示
- 🔊 Web Audio 音效（射击、爆炸、拾取道具），可静音
- 📱 支持键盘与触屏操作
- 🏆 5 关通关，敌军随关卡变强

## 🎮 操作方式

| 操作 | 键盘 | 触屏 |
|------|------|------|
| 移动 | `W A S D` 或 方向键 | 方向键按钮 |
| 射击 | `空格` 或 `J` | 开火按钮 |
| 暂停 | `P` | — |
| 开始 / 重新开始 | `回车` | 点击「开始」 |
| 静音 | `M` | 点击 🔊 |

## 🚀 运行方式

直接用浏览器打开 `index.html` 即可游玩，也可通过任意静态服务器托管。

### 在线游玩（GitHub Pages）

1. 进入仓库的 **Settings → Pages**
2. 在 **Branch** 中选择 `main` 分支、`/ (root)` 目录，点击 **Save**
3. 稍等片刻，即可通过 `https://<用户名>.github.io/<仓库名>/` 访问

## 🛠️ 技术要点

- `<canvas>` 绘制游戏画面，适配高 DPI 屏幕
- 基于网格的地图与矩形碰撞检测
- `requestAnimationFrame` 游戏循环 + 时间增量控制
- Web Audio API 实时合成音效
- `localStorage` 保存最高分
